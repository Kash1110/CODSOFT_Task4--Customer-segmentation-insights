# CODSOFT_Task4--Customer-segmentation-insights
Customer-Level Aggregation: Computed Recency (days since last purchase), Frequency (order count), and Monetary value (total spend) alongside primary region and age bracket.  RFM Quantile Scoring: Scored customers on a 1–4 scale across R, F, and M metrics to classify buyers into four actionable tiers: VIP Champions, Loyal Regulars, At-Risk
